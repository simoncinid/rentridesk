# Decisioni

- React Router è scelto per stabilità e route annidate.
- La coda è persistente in PostgreSQL; nessuna operazione ufficiale dipende solo dalla memoria.
- Le tabelle di codifica condividono `ref_codes` con viste per famiglia per mantenere versioni e snapshot.
- Il mock è una capability esplicita, mai presentata come invio RENTRI.
- I colori CSS sono neutrali e sostituibili; nessun marchio esterno è copiato.
