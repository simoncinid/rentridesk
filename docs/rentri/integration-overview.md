# Integrazione RENTRI

La fonte di verità è la documentazione ufficiale. Il codice espone un contratto di dominio dietro adapter; il solo adapter attivo nel repository è `MockRentriAdapter`. `demo` e `production` non devono essere marcati disponibili prima di boarding, certificato, test e verifica degli schemi.

Il 14 luglio 2026 sono state riesaminate la documentazione interoperabilità, le specifiche registro, la guida xFIR e il registro aggiornamenti. RENTRI ha attivato le funzioni FIR digitale il 13 febbraio 2026 e ha pubblicato aggiornamenti API successivi: per questo il check del changelog è parte del rilascio.
